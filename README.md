### Selected work

**[zodi4c-storage](https://github.com/zodi4ctvn/zodi4c-storage)**
Shared storage system for QBCore and Qbox (QBX) servers. Players create their own
storages, share them by password or membership, and store items through `ox_inventory`.
Full NUI interface, activity logs and a bilingual Turkish/English front end.

`Lua` · `FiveM` · `ox_inventory` · `MySQL`

**[coc-bb-autoattack](https://github.com/zodi4ctvn/coc-bb-autoattack)**
Automation for Clash of Clans builder base attacks.
